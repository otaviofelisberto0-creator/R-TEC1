Configurar repositório

Informe uma vez o endereço do repositório GitHub. O endereço fica salvo somente neste navegador.

Publicar JSON mensal

O login ocorre no domínio oficial do GitHub. A página TEC1 não recebe nem armazena sua senha.
1. Entrar no GitHub2. Carregar JSON em dados3. Editar manifest.jsonVoltar ao Dashboard

Ordem de publicação

  1. Entre no GitHub.
  2. Carregue o arquivo mensal, por exemplo 26-08-tec1.json, na pasta dados.
  3. Confirme em Commit changes.
  4. Edite dados/manifest.json e inclua a nova competência.
  5. Confirme o segundo commit e atualize o dashboard com Ctrl + F5.
